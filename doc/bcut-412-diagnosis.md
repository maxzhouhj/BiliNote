## 已修改

- 采用已观察到成功的浏览器请求头；JSON Content-Type 仅用于 POST。
- 上传、创建、查询统一 model_id=8，并给网络请求加超时。
- 普通查询从每秒一次改为每五秒一次；412、429、部分 5xx 及连接错误只做有限次数的 20/40 秒退避。
- 保存与音频文件大小、修改时间关联的远端任务句柄。重试优先续查，避免重复上传。
- 若服务明确返回 ASR state=3、HTTP 404/410 或任务不存在/过期的业务消息，清除不可续查的句柄，使后续手动重试可以新建任务；412、网络错误及未知业务错误仍保留句柄。
- 缓存不是 JSON 对象、任务 ID 类型错误或音频指纹不符时，忽略缓存并正常创建任务。
- 不再在日志中输出分片标识、上传下载签名链接或完整响应。
